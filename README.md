# Ankinize examples

Small, runnable projects built with [Ankinize](https://ankinize.com), the Anki sync server with a REST API. Each folder is self-contained.

| Example | What it shows |
|---|---|
| [`browser-extension`](browser-extension) | A WXT + Base UI extension: select text, click the export button, get a card |

You need an Ankinize account and an API key from **API Keys &amp; Devices**. Docs: [https://ankinize.com/docs](https://ankinize.com/docs). New examples are welcome: one folder, its own README.
