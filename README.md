# Ankinize examples

Small, runnable projects built with [Ankinize](https://ankinize.com), the Anki sync server with a REST API. Each folder is self-contained.

| Example | What it shows |
|---|---|
| [`article-to-flashcards`](article-to-flashcards) | A script that turns a web page into Anki cards with an LLM |
| [`ai-agent`](ai-agent) | A tool-calling agent that reads and writes your Anki |
| [`browser-extension`](browser-extension) | A Manifest V3 extension: select text, right-click, get a card |

You need an Ankinize account (or your own server) and an API key from **API Keys & Devices**. Docs: https://ankinize.com/docs. SDK: [`@ankinize/sdk`](https://www.npmjs.com/package/@ankinize/sdk).

These examples are independent of Anki and AnkiWeb. Anki is a registered trademark of Ankitects Pty Ltd. Licensed MIT.

New examples are welcome: one folder, its own README and `package.json`, nothing committed that holds a key.
